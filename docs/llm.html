Every model on this machine, dense against MoE

llmctl bench on llama.cpp v0.6.0 (Vulkan b11429, ROCm b1340), pp512 and tg128 in tokens per second, flash attention on, the machine otherwise idle (2026-10-07). Decode is bound by the memory bandwidth: a dense model reads all its weights for every token, a MoE model only its active experts — so the MoE models decode 5–13× faster than dense ones of their size, and Kolibri-1 with 78B weights decodes faster than an 8B dense model. Vulkan beats ROCm almost everywhere, except Scout. Kolibri runs on its own patched build (Vulkan only).
