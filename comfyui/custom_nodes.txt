# Custom node packs llmctl installs into ComfyUI (download comfy / update comfy).
# One pack per line:  <directory>  <git URL>  <commit>  [-<requirement to drop>|+<requirement to add> ...]
# The commit is pinned: update moves a pack only when this file names a new one.
# Requirements install into ComfyUI's venv with torch held to its ROCm build;
# a "-name" drops that requirement, a "+name" adds one.

# Qwen3-TTS: voice design, cloning, dialogue. Its requirements name the Intel
# OpenVINO build of onnxruntime; its 25 Hz tokenizer imports onnxruntime at load
# (the 12 Hz models used here never run it), so the plain CPU build does.
ComfyUI-Qwen-TTS  https://github.com/flybirdxx/ComfyUI-Qwen-TTS  a1328c8a731eff82cf4c205b31bdfb7f29d817f4  -onnxruntime-openvino  +onnxruntime

# ControlNet preprocessors: pose (DWPose) and depth (Depth Anything V2) maps
# from a photo, for the Qwen-Image 2.1 Pose and Depth Control workflows. Its
# requirements name onnxruntime-gpu, a CUDA build — the plain onnxruntime
# already here runs DWPose's detector — and mediapipe, which only its face-mesh
# node uses and which has no build for this Python. Its detector models come
# from Hugging Face on first use, into the pack's own ckpts/.
comfyui_controlnet_aux  https://github.com/Fannovel16/comfyui_controlnet_aux  0cd290477128d42cdc3e76a826a402d866e8c684  -onnxruntime-gpu  -mediapipe

# Detailer: finds faces and hands, repaints each crop at a higher resolution and
# pastes it back (Qwen-Image 2.1 Detailer workflows). SAM 2 is optional there and
# builds a CUDA extension from git — left out; SAM 1 (segment-anything) is pure
# Python and outlines the found object for the mask.
ComfyUI-Impact-Pack  https://github.com/ltdrdata/ComfyUI-Impact-Pack  429d0159ad429e64d2b3916e6e7be9c22d025c3c  -git+https://github.com/facebookresearch/sam2
# Its YOLO detectors (ultralytics, AGPL-3.0); models from Bingsu/adetailer.
ComfyUI-Impact-Subpack  https://github.com/ltdrdata/ComfyUI-Impact-Subpack  50c7b71a6a224734cc9b21963c6d1926816a97f1

# rgthree: comfort in the ComfyUI UI — a progress bar, group bypass/mute,
# seed control, an image comparer, context nodes, the power lora loader. No
# models, no requirements. The bundled workflows use none of its nodes.
rgthree-comfy  https://github.com/rgthree/rgthree-comfy  449c58fcdd612f7733e54c51f6758ead63fa180b

# Background removal and masks: BiRefNet (MIT) for the BiRefNet Background
# Removal workflows, plus segmentation nodes. Its requirements name onnxruntime-gpu
# (CUDA) and transparent-background, which only its INSPYRENET model uses and
# which pulls the original albumentations over comfyui_controlnet_aux's
# albumentationsx; decord, which its bundled SAM 3 imports at load, has no build
# for this Python — eva-decord, the maintained fork, has. Its models come from
# Hugging Face on first use, or from download comfy, into models/RMBG/.
ComfyUI-RMBG  https://github.com/1038lab/ComfyUI-RMBG  229529e0ea63fb7085848225d74f91f6dc164956  -onnxruntime-gpu  -transparent-background  -decord  +eva-decord

# Inpaint on a crop around the mask, stitched back (the Inpaint Crop workflows).
# No requirements.
ComfyUI-Inpaint-CropAndStitch  https://github.com/lquesada/ComfyUI-Inpaint-CropAndStitch  8584b08d851762965df898b421a39075fc5357ae

# Florence-2: a detailed caption of a picture (the prompt Qwen-Image Layered
